# 開発計画書：外部対応タスク管理ダッシュボード

参照元仕様書：`docs/仕様書_外部対応タスク管理ダッシュボード.md`

一気に全機能を実装せず、以下のPhaseに分けて段階的に開発する。各Phaseの進捗は、リンク先の進捗報告書に記録する。

## Phase 0：環境確認・設計レビュー

- Next.js / Supabase / shadcn/ui の動作確認（済）
- 仕様書の内容レビュー、DBテーブル構成のたたき台作成
- 進捗報告書：[docs/progress/Phase0_進捗報告書.md](./progress/Phase0_進捗報告書.md)

## Phase 1：データベース設計・テーブル作成

- Supabaseに `tasks`（タスク）テーブルを作成
- `channel_type`（相手先区分）、`status`（ステータス）などの区分値を定義
- Supabase Authでユーザー管理の下地を作る（担当者選択用）
- 進捗報告書：[docs/progress/Phase1_進捗報告書.md](./progress/Phase1_進捗報告書.md)

## Phase 2：認証機能

- Supabase Authによるログイン／ログアウト画面の実装
- ログイン後のみダッシュボードにアクセスできるよう制御
- 進捗報告書：[docs/progress/Phase2_進捗報告書.md](./progress/Phase2_進捗報告書.md)

## Phase 3：タスクの登録・一覧・編集（CRUD）

- 新規タスク登録フォームの実装
- タスク一覧表示（フィルタ・ソート機能付き）
- ステータスのワンクリック変更
- 進捗報告書：[docs/progress/Phase3_進捗報告書.md](./progress/Phase3_進捗報告書.md)

## Phase 4：ダッシュボード・集計機能

- ステータス別・担当者別の件数サマリー表示
- 期限超過タスクのハイライト表示
- 自分の担当タスクのみの絞り込みビュー
- 進捗報告書：[docs/progress/Phase4_進捗報告書.md](./progress/Phase4_進捗報告書.md)

## Phase 5：仕上げ・デプロイ準備

- 表示崩れ・動作確認（スマホ含む）
- Vercelへのデプロイ
- 進捗報告書：[docs/progress/Phase5_進捗報告書.md](./progress/Phase5_進捗報告書.md)

## 将来拡張（本計画の対象外）

- Gmail API連携による自動取り込み
- 期限リマインドのGmail自動送信
- eFax内容のAI自動解析・タスク自動登録
